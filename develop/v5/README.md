# V5 독립 단타 전략

V5는 V4의 ETH 4시간봉 전략과 별개로, `KRW-BTC` 한 티커만 짧게 거래하는 단타 봇입니다.
두 봇은 같은 시간에 실행할 필요가 없습니다. V4와 V5를 각각 다른 crontab 주기로 등록해도
되며, 실행 시마다 실제 주문 가능 원화를 다시 조회합니다.

## 자금 분리

공용 설정 [`develop/portfolio.py`](../portfolio.py)에서 신규 매수 한도를 나눕니다.

| 전략 | 티커 | 신규 매수 최대 한도 | 역할 |
| --- | --- | ---: | --- |
| V4 | `KRW-ETH` | 700,000 KRW | 4시간봉 RSI 회복 스윙 |
| V5 | `KRW-BTC` | 300,000 KRW | 5분봉 반등 단타 |

예를 들어 원화가 1,000,000원일 때 V5가 먼저 300,000원을 쓰면 V4는 남은 700,000원 안에서만
주문합니다. 반대로 V4가 먼저 700,000원을 쓰면 V5는 남은 300,000원 안에서만 주문합니다.
각 봇은 `min(실제 가용 원화, 자기 한도)`만 주문하므로, 크론 실행 순서와 무관하게 원화보다 큰
주문을 내지 않습니다. 한도 값은 실행 중 보유한 코인의 평가액을 강제로 줄이는 값이 아니라,
**새로운 매수 한 번**에 사용할 최대 원화입니다.

## 진입과 청산

1. 완료된 5분봉에서 RSI(7)가 40 아래에서 위로 회복합니다.
2. 바로 전 5분봉 종가가 볼린저 하단 밴드(20, 2.5σ) 아래이고, 최신 종가는 하단 밴드 위로 돌아옵니다.
3. 최신 종가가 5분봉 SMA(50) 위에 있을 때만, 앞의 두 조건이 맞으면 시장가로 진입합니다.
4. 실제 매수 체결을 확인한 다음, 매수·매도 수수료를 반영해 **순이익 +0.1%** 이상을 목표로 한
   지정가 매도를 등록합니다.
5. 지정가가 체결되기 전에 진입가보다 1% 내려가거나 90분이 지나면 지정가를 취소하고 시장가로
   청산합니다.

목표 순이익률은 실제 주문 원화에 비례합니다. 예를 들어 300,000원 주문이면 순이익 목표는
300원이고, 150,000원 주문이면 150원입니다. 호가 단위와 실제 체결 가격 때문에 정확한 금액은
달라질 수 있지만, 계산한 목표가를 업비트 KRW 호가 단위로 올림하므로 목표보다 조금 더 남는
방향입니다.

## 실제 실행 상태

V5는 한 번의 크론 실행에서 모든 주문을 서두르지 않습니다. 시장가 매수 뒤에는
`trade_state.json`에 `ENTRY_PENDING`을 저장하고, 다음 실행에서 체결 수량을 확인한 뒤 목표가
주문을 만듭니다. 손절·시간 청산도 먼저 목표가 주문을 취소하고, 다음 실행에서 수량이 풀린 것을
확인한 뒤 시장가로 정리합니다. 주문 상태가 예상과 다르거나 상태 파일 없이 BTC가 보이면 자동
주문을 멈추고 로그를 남깁니다.

`trade_state.json`과 `trade_log.txt`는 로컬 운영 파일이며 Git에 올리지 않습니다.

## 백테스트

```bash
# 기본 기간(2026-07-01부터 최신 완료 5분봉) PNG 생성
make backtest v5

# 원하는 기간과 실제 가상 체결 RSI 점 표시
make backtest v5 FROM=2026-07-01 TO=2026-08-02 SHOW_RSI_SIGNAL_POINTS=1
```

백테스트는 5분봉 종가로 신호를 만들고, 미래 가격을 보지 않도록 다음 5분봉 시가에 시장가
매수가 체결된 것으로 가정합니다. 이후의 각 5분봉 고가·저가로 목표가·손절 도달을 계산합니다.
한 봉 안에서 목표가와 손절가를 모두 건드렸다면 실제 순서를 알 수 없으므로 보수적으로 손절을
먼저 적용합니다. `BacktestConfig.cron_interval_minutes`는 이 시뮬레이션 전용 가정이며, 실제
`btc_bot.py`는 이 값을 사용하지 않습니다.

5분봉 과거 데이터는 기존 공용 캐시 `develop/v3/backtesting/cache/KRW-BTC__minute5.csv`에
저장됩니다. 다음 실행에서는 요청 구간 중 캐시에 없는 앞·뒤 부분만 업비트 API로 호출합니다.

## 주의

2026-01-01~2026-08-03, 5분 크론 가정의 현재 기본값은 +0.91%, 최대 낙폭 -0.65%, 34회
체결이었습니다. 같은 규칙을 1~4월과 5~8월로 나눠도 각각 +0.79%, +0.12%였습니다. 표본과
수익이 모두 작으므로 수익 전략으로 단정할 수는 없습니다. 짧은 목표 이익은 수수료, 호가 단위,
슬리피지, 지정가 미체결의 영향을 크게 받습니다. 실제 crontab 등록 전에는 추가 기간 결과와
최대 낙폭을 확인하고, 주문 키 권한도 최소화하세요.
