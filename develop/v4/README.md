# V4 RSI 회복 전략

V4는 V3의 단순 과매도 매수를 바꾼 실험 전략이다. 가격이 계속 하락하는 동안 RSI가 낮다는
이유만으로 반복 매수하지 않고, RSI가 과매도권에서 **회복하는 순간**에만 한 번 진입한다.

이 폴더의 기본 대상은 `KRW-ETH`, 전략 RSI 봉은 4시간봉(`minute240`)이다.

## 매매 규칙

| 구분 | 기본값 | 의미 |
| --- | ---: | --- |
| 매수 | 이전 RSI `< 40`, 현재 RSI `≥ 40` | RSI가 40 아래에서 위로 회복할 때 가용 원화 전액 매수 |
| 익절 | 수익률 `≥ +3%` | RSI와 관계없이 전량 익절 |
| 손절 | 수익률 `≤ -10%` | RSI와 관계없이 전량 손절 |
| RSI 청산 | RSI `≥ 75` | 익절·손절에 먼저 걸리지 않아도 전량 청산 |
| 최소 주문 | 5,000 KRW | 업비트 최소 주문 금액보다 작으면 주문하지 않음 |
| 수수료 가정 | 주문당 0.05% | 백테스트의 매수·매도 모두에 적용 |

진입 판단의 `이전 RSI`는 직전 1시간 실행의 RSI가 아니다. 현재 부분 4시간봉 바로 전의
**직전 4시간 전략 봉 RSI**다. 따라서 한 4시간봉 안에서 RSI 값이 출렁여도, 이전 전략 봉을
기준으로 한 회복 조건은 변하지 않는다.

```text
이전 4시간 RSI < 40, 현재 4시간 RSI ≥ 40
                    ↓
                 전액 매수
                    ↓
  -10% 손절 ──┬── +3% 익절 ──┬── RSI 75 이상 청산
              ↓               ↓
                           전량 매도
```

## V3와의 차이

V3는 RSI가 30 이하인 동안 가용 원화의 20%씩 매수한다. V4는 RSI가 40을 다시 넘는 한 번의
회복 시점에만 진입한다. 또한 V4는 정해진 익절·손절로 보유 위험을 제한한다.

## 백테스트 가정

- 기본 크론 가정은 60분이다. 이는 백테스트에서만 사용하며, 실서버 실행 주기는 crontab이 정한다.
- 60분 원본 봉으로 매 시점의 부분 4시간봉 RSI를 다시 계산한다.
- 신호는 원본 봉 종가까지의 정보만 사용하고, 주문은 다음 원본 봉 시가에 체결된 것으로 계산한다.
- 시작 원금은 1,000,000 KRW이며, 수수료는 매수·매도 각각 0.05%다.
- 원본 OHLCV는 `develop/v3/backtesting/cache/`의 V3 캐시를 그대로 재사용한다. 가격 데이터만 공유하며 전략 결과는 공유하지 않는다.

## 이번 연구 결과

2026-01-01부터 2026-08-03의 최신 완료 봉까지, 60분 크론 가정으로 계산한 결과다.

| 전략 | 체결 수 | 최종 자산 | 총수익률 |
| --- | ---: | ---: | ---: |
| V3 | 48 | 622,820 KRW | -37.72% |
| V4 | 39 | 1,058,343 KRW | +5.83% |

V4의 같은 구간 최대 낙폭은 -21.07%다. 이 수치는 과거 한 구간의 백테스트 결과이며, 미래
수익이나 실거래 성과를 보장하지 않는다. `research.py`로 기간을 나눠 다시 검증한 뒤에만
실제 crontab 등록 여부를 결정한다.

## 실행

```bash
# V4 PNG 생성: 2026-01-01부터 최신 완료 봉까지
make backtest v4

# 기간과 RSI의 실제 체결 점을 지정해 PNG 생성
make backtest v4 FROM=2026-01-01 TO=2026-08-02 SHOW_RSI_SIGNAL_POINTS=1

# 후보 조합 연구: 수수료·다음 봉 시가 체결 가정은 백테스트와 동일
python3 develop/v4/research.py --from 2026-01-01 --to 2026-08-02 --cron-interval-minutes 60

# 실제 주문 실행. crontab 등록 전에는 실행하지 않는다.
python3 develop/v4/btc_bot.py
```

## 파일 역할

- `config.py`: 티커, RSI 봉, V4 기본 파라미터, 백테스트 가정
- `trade_logic.py`: API 호출 없는 순수 신호·매매 판단 함수
- `btc_bot.py`: 실제 업비트 주문과 알림·자산 로그 처리
- `backtesting/backtest_logic.py`: 크론·수수료·다음 봉 시가를 가정한 순수 시뮬레이터
- `backtesting/backtest_visualizer.py`: 결과 PNG 생성기
- `research.py`: 작은 파라미터 격자를 비교하는 후보 연구 도구
- `tests/`: 순수 매매 판단과 백테스트 로직 단위 테스트
